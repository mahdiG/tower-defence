# KayKit Skeleton Enemies

All models and weapons in this folder come from the free **KayKit Character Pack:
Skeletons** by Kay Lousberg.

- Source: https://github.com/KayKit-Game-Assets/KayKit-Character-Pack-Skeletons-1.0
- Original release: https://kaylousberg.itch.io/kaykit-skeletons
- License: CC0 1.0 Universal (see `KayKit_Skeletons_LICENSE.txt`)
- Downloaded: 2026-11-06

Files:

- `Skeleton_Minion.glb` — minion enemy model.
- `Skeleton_Warrior.glb` — warrior enemy model.
- `Skeleton_Rogue.glb` — rogue enemy model.
- `Skeleton_Mage.glb` — mage enemy model.
- `weapons/` — weapon and accessory glTF files, their `.bin` buffers, and the
  shared `skeleton_texture.png` atlas.

The weapon glTF files reference `skeleton_texture.png` by a relative path, so
keep the texture next to the `.gltf`/`.bin` files.
